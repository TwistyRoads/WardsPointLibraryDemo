About this adaptation

Spoken dialogue is taken from the original WPL_01_HOOK, WPL_03_COMPETING_CLAIM, WPL_06_ATRIUM and WPL_07_DEBRIEF scripts. Traversal, combat abstractions and connective prose are adaptation material.

Your setup establishes earlier faction standing; it does not award the library. Whoever receives Eli’s first successful report and key handover becomes owner. Later changes to the library are suggested futures, not simulated events. Combat remains an abstract text interaction.

This is an independently authored, noncommercial Dying Light 2–style portfolio exercise. Not an official Techland or Dying Light 2 product.
